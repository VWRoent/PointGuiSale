# PointGuiSale

## 概要

**PointGuiSale** は、GUIベースの販売（レジ）管理アプリです。  
商品画像つきの数量入力、割引（資格）設定、履歴保存、備考（アンケート/メモ）記録、顧客管理をまとめて扱えます。

v2.0.0 では UI を大幅に刷新し、配色テーマ切替・顧客タブ・保存先の統一（PGS_info）・ウィンドウサイズ最適化などを追加しました。

---

## v2.0.0 の主な変更点

- **保存先を `PGS_info/` 配下に統一**（`images/`, `setting/`, `log/`）
- **配色テーマ切替**（管理から選択）
- **商品管理の強化**
  - 商品ID（3文字）で商品情報（名前/価格/画像）を呼び出し・再利用
  - 商品画像は `images/image_<商品ID>.png` として管理
- **顧客タブ追加**
  - 顧客の購入履歴（集計）と購入比率表示
  - 顧客情報（愛称・お仕事・名前変更）
  - 顧客画像の追加/選択（保存は `images/顧客ID_YYDD_??.<拡張子>`）
- **本日売上**表示 + **営業日更新時刻**（例 01:00）設定  
  ※更新時刻より前の売上は「前日」扱いで本日売上に集計
- **全タブ最下部に** `created by 紫波レント` を表示
- 起動時は **レジタブ**から開始

---

## 特徴

- **レジ**：商品数量の入力（ボタン/手入力）、割引反映、備考・質問（アンケート）記録、請求額のコピー
- **管理**：商品ID/商品名/価格/説明/画像の設定、テーマ選択、商品カラム数（左/右）の設定、ID反映
- **顧客**：顧客の購入傾向（比率）確認、愛称/お仕事/名前変更、顧客画像の登録
- **履歴**：販売履歴の保存/参照、選択行削除（確認あり）
- **備考**：備考（アンケート/メモ）の保存/参照、選択行削除（確認あり）
- **質問**：質問（回答項目/ラベル）設定
- **資格（割引設定）**：割引名と割引率を設定
- **設定**：ウィンドウサイズの計算設定、営業日更新時刻など

## インストール

### Windows（exe）

1. 右上の緑色ボタンの <> Code から Download ZIP でダウンロード  
2. 解凍(展開)  
3. `PointGuiSale.exe` をダブルクリック

### Python（CUIで起動）

1. リポジトリをクローンまたはダウンロード
   ```bash
   git clone https://github.com/VWRoent/PointGuiSale.git
   ```

2. 依存ライブラリをインストール

   ```bash
   pip install pillow
   ```
3. 実行

   ```bash
   python PointGuiSale.py
   ```

   ※配布ファイル名が `PointGuiSale_v2_0_0.py` の場合は、そちらを実行してください。

## 使い方（タブ順）

### 1) レジ

* 顧客（名前/ID）、割引、備考、質問を選択
* 商品の数量を入力（ボタン or 入力欄に数値を直接入力）
* 請求額は自動計算されます
* 「請求額コピー」は **数字のみ**コピーされます（そのまま貼り付け用）

### 2) 管理

* **商品数：左/右**を設定して反映（合計が商品数になります）
* **配色テーマ**を選択
* 商品設定

  * 商品ID（3文字）/ 商品名 / 価格 / 説明 / 画像
  * 画像は「画像」ボタンで選択し、`images/image_<商品ID>.png` に保存
* 「商品決定」で設定を保存
* 「ID反映」で商品IDに紐づく既存設定（名前/価格/画像/説明）を一括で呼び出し

### 3) 顧客

* 顧客を選択し、購入履歴（集計）と購入比率を確認
* 上部の欄で「愛称」「お仕事」「名前変更」を入力して「変更」
* 右側の画像エリアで顧客画像を追加/選択

### 4) 履歴

* 販売履歴を参照
* 選択行削除（確認ポップアップあり）

### 5) 備考

* 備考（アンケート/メモ）履歴を参照
* 選択行削除（確認ポップアップあり）

### 6) 質問

* 質問（回答項目）を設定

### 7) 資格（割引設定）

* 割引名と割引率（%）を設定

### 8) 設定

* ウィンドウの幅・最小幅、1行高さ、最小行数などを調整
* 営業日更新時刻（例 01:00）を設定

## 保存される場所（v2.0.0）

プログラムと同じ場所に `PGS_info/` が作成され、以下に保存されます。

### `PGS_info/setting/`（設定）

* `products.csv`（商品：基本）
* `product_catalog.csv`（商品IDでの呼び出し用カタログ）
* `column_counts.csv`（左/右カラム数）
* `qualifications.csv`, `qualification_count.csv`（割引設定）
* `question_responses.csv`（質問/回答項目）
* `customers.csv`（顧客情報）
* `ui_theme.txt`（配色テーマ）
* `window_settings.csv`（ウィンドウサイズ設定）
* `business_day_cutoff.txt`（営業日更新時刻）
* `shop_name.txt`, `persistent_text.txt` など

### `PGS_info/log/`（ログ）

* `log.csv`（販売履歴）
* `survey_log.csv`（備考/アンケート）
* `management_log.csv`（管理変更ログ）
* `qualification_log.csv`（割引設定変更ログ）
* `customer_notes.csv`（顧客メモ等）

### `PGS_info/images/`（画像）

* `image_<商品ID>.png`（商品画像）
* `<顧客ID>_YYDD_??.<拡張子>`（顧客画像：?? は 00,01,02…）
